## Setting up automation in Azure DevOps and GitHub Actions

[Jan Bakker](https://janbakker.tech/) has created a step-by-step guide showing how to set up M365Advisor in Azure DevOps and GitHub Actions (using client secrets). Note that if you have access to an Azure subscription we recommend using the Workload Identity Federation guide since it is more secure and does not require secrets or certificates to be rotated.
